\# 🚀 Easy DNSTT Tunnel (راه‌اندازی آسان تونل DNS) یک اسکریپت خودکار، هوشمند و جامع برای نصب، پیکربندی و مدیریت سرور \*\*DNSTT (DNS Tunnel)\*\* در لینوکس. این پروژه امکان دور زدن محدودیت‌های اینترنت و برقراری ارتباط امن از طریق پروتکل DNS (شامل UDP DNS, DoH, DoT) را به‌صورت ۱ کلیکه و آسان فراهم می‌سازد. \--- \#\# 📋 فهرست مطالب \- \[ویژگی‌ها و امکانات\](\#-ویژگی‌ها-و-امکانات) \- کلیکه:\*\* دانلود باینری‌های رسمی، تنظیم دسترسی‌ها و پیکربندی بدون نیاز به دخالت دستی. \* \*\*⚙️ پشتیبانی از سرویس‌دهی SSH و SOCKS5:\*\* امکان تونل‌کردن ترافیک به سمت پورت SSH سرور (پورت ۲۲) یا پروکسی SOCKS5. \* \*\*🛡️ اجرای غیر Root جهت امنیت بالا:\*\* اجرا در قالب کاربر ایزوله سیستم جهت جلوگیری از دسترسی‌های غیرمجاز. \* \*\*🔄 هدایت پورت (Port Forwarding):\*\* انتقال خودکار ترافیک از پورت عمومی DNS (پورت UDP 53\) به پورت داخلی DNSTT (پورت 5300\) از طریق \`iptables\` / \`UFW\`. \* \*\*🛠️ منوی مدیریت تعاملی (CLI Panel):\*\* \* مشاهده وضعیت سرویس و پورت‌های فعال. \* استارت، استاپ و ریستارت هوشمند سرویس. \* مشاهده لاگ‌های زنده (Live Logs). \* تولید و نمایش کلید عمومی (Public Key) و کانفیگ‌های آماده برای کلاینت‌ها. \* تغییر دامنه و مقدار MTU به‌صورت منومحور. \* \*\*📦 یکپارچگی با Systemd:\*\* ایجاد سرویس خودکار جهت شروع مجدد پس از ریبوت سرور و پایداری بالا. \* \*\*🌐 پشتیبانی از توزیع‌های مختلف:\*\* سازگار کامل با Ubuntu, Debian, CentOS, AlmaLinux, Fedora و ... \--- \#\# 🌐 پیش‌نیازها 1\. یک سرور مجازی (VPS) با سیستم‌عامل لینوکس (ترجیحاً \*\*Ubuntu 20.04+\*\* یا \*\*Debian 11+\*\*). 2\. دسترسی \`root\` یا مجوز \`sudo\`. 3\. یک نام دامنه (Domain) که مدیریت DNS آن در اختیار شما باشد (مثلاً روی Cloudflare یا ArvanCloud). \--- \#\# 🎯 تنظیمات رکوردهای DNS (بسیار مهم) قبل از اجرای اسکریپت روی سرور، باید رکوردهای DNS زیر را در پنل مدیریت دامنه‌تان ثبت کنید. فرض کنید دامنه شما \`example.com\` و آی‌پی سرور شما \`1.2.3.4\` است: 1\. \*\*یک رکورد A (بدون پروکسی / DNS Only):\*\* \* \*\*Name / Host:\*\* \`ns\` (یا هر نام دلخواه مثل \`dnstns\`) \* \*\*IPv4 Address:\*\* \`1.2.3.4\` (آی‌پی سرور شما) \* \*\*Proxy Status:\*\* غیرفعال (خاموش / خاکستری) 2\. \*\*یک رکورد NS:\*\* \* \*\*Name / Host:\*\* \`t\` (یا هر زیردامنه‌ای که برای تونل می‌خواهید، مانند \`dns\`) \* \*\*NS Value / Target:\*\* \`ns.example.com\` \> ⚠️ \*\*نکته:\*\* دامنه نهایی تونل شما \`t.example.com\` خواهد بود. تمام درخواست‌های ارسال شده به زیردامنه‌های \`\*.t.example.com\` به آی‌پی سرور شما هدایت خواهند شد. \--- \#\# ⚡ نصب و اجرای سریع جهت نصب و اجرای اسکریپت، کافیست دستور زیر را در ترمینال سرور خود اجرا کنید: \`\`\`bash bash \<(curl \-sL https://raw.githubusercontent.com/hosseinit1988/easy-dnstt-tunnel/main/DNSTT-Tunnel.sh) \`\`\` با اجرای این دستور، مراحل زیر به‌صورت تعاملی طی می‌شود: 1\. دریافت نام دامنه تونل (مثلاً \`t.example.com\`). 2\. تعیین پورت و نوع سرویس مقصد (SSH پورت 22 یا پروکسی SOCKS5). 3\. تنظیم مقدار MTU (پیش‌فرض: \`1232\`). 4\. ساخت کلیدهای رمزنگاری (\`server.key\` و \`server.pub\`). 5\. راه‌اندازی سرویس \`dnstt-server\` روی سرور. \--- \#\# 🖥️ راهنمای منوی مدیریت پس از اولین نصب، هر زمان که اسکریپت را مجدداً اجرا کنید، \*\*منوی مدیریت تعاملی\*\* نمایش داده می‌شود: \`\`\`text \*\*NapsternetV\*\* استفاده کنید: \* \*\*DNS Server / Resolver:\*\* آی‌پی DNS اپراتور یا سرویس‌دهنده‌های عمومی (مانند \`1.1.1.1\` یا \`8.8.8.8\`). \* \*\*DNS Subdomain / Domain:\*\* \`t.example.com\` \* \*\*Public Key:\*\* کلید عمومی نمایش داده شده در گزینه ۱ منوی اسکریپت. \* \*\*Forward Port:\*\* \`127.0.0.1:7000\` (جهت اتصال SSH یا V2Ray). \--- \#\#\# ۲. اتصال در دسکتاپ برنامه کلاینت DNSTT را بر اساس سیستم‌عامل خود دریافت کرده و دستور زیر را در ترمینال یا Command Prompt اجرا کنید: \#\#\#\# اجرای کلاینت (حالت UDP): \`\`\`bash ./dnstt-client \-udp 8.8.8.8:53 \-pubkey-file server.pub t.example.com 127.0.0.1:7000 \`\`\` \#\#\#\# اجرای کلاینت (حالت DoH \- DNS over HTTPS): \`\`\`bash ./dnstt-client \-doh https://cloudflare-dns.com/dns-query \-pubkey-file server.pub t.example.com 127.0.0.1:7000 \`\`\` پس از اجرای کلاینت، پورت local \`7000\` روی سیستم شما باز می‌شود و می‌توانید با SSH به آن متصل شوید: \`\`\`bash ssh \-p 7000 root@127.0.0.1 \`\`\` \--- \#\# 🔧 تنظیمات سفارشی و عیب‌یابی \#\#\# راهنمای تنظیم MTU مقدار پیش‌فرض MTU عدد \*\*1232\*\* است. اگر با کندی یا قطع اتصال مواجه شدید: \* \*\*شبکه‌های با کیفیت و با ثبات:\*\* \`1400\` \* \*\*شبکه‌های استاندارد:\*\* \`1232\` (توصیه‌شده) \* \*\*شبکه‌های موبایل با اختلال زیاد:\*\* \`512\` تا \`1100\` \#\#\# بررسی لاگ‌ها و وضعیت سرویس در صورت نیاز به بررسی مستقیم سرویس در لینوکس: \`\`\`bash \# بررسی وضعیت سرویس sudo systemctl status dnstt-server \# مشاهده لاگ‌ها sudo journalctl \-u dnstt-server \-f \-n 50 \# بررسی پورت‌های باز sudo ss \-tulnp | grep \-E "53|5300" \`\`\` \--- \#\# 🔐 امنیت و بهینه‌سازی 1\. \*\*ایزوله‌سازی دسترسی:\*\* سرویس \`dnstt-server\` تحت یک کاربر سیستمی بدون دسترسی Shell اجرا می‌شود. 2\. \*\*فایروال (Firewall):\*\* اسکریپت به‌طور خودکار رول‌های \`iptables\` لازم برای پورت 53 UDP را تنظیم می‌کند تا ترافیک به پورت داخلی 5300 منتقل شود. 3\. \*\*کلید اختصاصی:\*\* برای هر نصب یک کلید عمومی/خصوصی اختصاصی با الگوریتم ECC تولید می‌شود که تضمین‌کننده امنیت و احراز هویت تونل است. \---
